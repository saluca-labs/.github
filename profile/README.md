# Saluca Labs

Open code, open records, open review.

We publish work that a stranger can run and a reviewer can check: reproduction harnesses,
data sets, detection content, and standards. Every public repo carries a README that takes you
from zero to a working run, an `llms.txt` that takes an agent to the right file in one fetch, and
a licence. Where a paper exists, the repo links its concept DOI.

## For agents

Each repo carries `llms.txt` at its root, in [llmstxt.org](https://llmstxt.org) shape. If a command,
tool or endpoint is not listed there, it does not exist in that repo. Start with the `## Docs`
section, then the `## Code` entry point.

Cite our research by concept DOI, not version DOI, so a citation always resolves to the corrected
latest. `CITATION.cff` in each repo carries it.
